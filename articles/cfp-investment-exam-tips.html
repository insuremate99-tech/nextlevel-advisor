ทริคสอบผ่าน CFP Module 2 วางแผนการลงทุน ฉบับคนไม่เก่งคำนวณ

5 เทคนิคเอาตัวรอดสอบ Module วางแผนการลงทุน ที่คำนวณหนักสุด ฉบับคนไม่ชอบทั้งคำนวณและท่องจำ

22 มิ.ย. 2569 · อ่าน 4 นาที · โดย ป้อง | AFPT™ FChFP

ใครที่แพลนว่าอยากลองสอบคุณวุฒิวางแผนการเงิน พูดก่อนเลยว่า เราไม่ใช่สายคำนวณเลยยย เจอสูตรเยอะๆ ก็กดผิด กดถูก เดี๋ยวเล่าให้ฟังวิธี วิธีเอาตัวรอด ของ Module วางแผนการลงทุน ที่ถือว่าเป็นชุดที่คำนวณหนักอยู่ ฉบับคนไม่ชอบทั้งคำนวณ และการท่องจำครับ

1. ข้อไหนชัวร์ เก็บก่อน

ทำข้อที่อ่านปราดเดียว แล้วกาได้ทันทีก่อน ค่อยทยอยมาเก็บพาร์ทที่ซับซ้อน + คำนวณ เจอข้อไหนที่ดูทรงแล้วงมกดเครื่องคิดเลขหลายตลบ... ข้ามจ้าาา อย่าให้อีโก้ มาลากเวลาพังทั้งชุด

2. จรรยาบรรณตรงไปตรงมากว่าที่คิด

พาร์ตนี้ไม่ต้องคิดซับซ้อน และเล่นคำกำกวม เท่าตอนสอบ Module 1 แค่มี Common sense พอถูไถ พาร์ตนี้เราได้ 93.33% (คนดีย์ไง) ถือว่าเป็นหมวดที่ควรเก็บให้ได้

3. ไม่ต้องจำสูตรเป๊ะ แต่ต้องรู้ว่ามันบอกอะไร

สูตร Sharpe, Treynor หรือ SD... ท่องไปเดี๋ยวก็ลืมครับ (ฉันเอง) โฟกัสแค่ว่าอัตราส่วนพวกนี้เอาไว้วัดอะไร? ส่วนเรา ถึงบางอันจำสูตรได้ แต่ก็ขี้เกียจทำข้อคำนวณบางข้ออยู่ดี 5555

4. มี IC License อยุ่แล้ว ใิช้สิทยกเว้นคอร์สเรียนได้

หลายคนไม่รู้ว่าถ้าถือใบอนุญาต IC อยู่แล้ว ใช้ยื่น Skip การอบรมได้ ประหยัดค่าคอร์สไปได้เป็นหมื่นเลย ปล. มีค่าธรรมเนียมเทียบเคียงสิทประมาณพันกว่าบาท ก็ดีกว่าเสียค่าเรียนหมื่นนึง + เวลาเรียนง่ะ

5. ระวังหมวด "การจัดพอร์ต" & วัดผลตอบแทน

หมวดการวิเคราะห์พอร์ตลงทุน เป็นจุดที่คะแนนเฉลี่ยคนสอบต่ำสุด เพราะมันท่องไปสอบไม่ได้ คุณต้องเข้าใจจริงๆ ว่า "ทำไม" ถึงต้องจัดสินทรัพย์หน้าตาแบบนี้ในสถานการณ์นี้ และวัดผลตอบแทนยังไง (ซึ่งก็คำนวณอีกเป็นยวง)

ท้ายที่สุด CFP ไม่ใช่ข้อสอบวัดความจำสูตรคณิตศาสตร์ แต่ถามว่าต้องจำมั้ย ก็ต้องจำอยุ่ดี .....เลือกว่าจะจำสูตรไปทำ หรือพร้อมมั่ว 5555 เอาแค่สอบเนอะ

ตอนนี้ขยับมาเป็น Certified AFPT เต็มตัวแล้วน๊าาา ใครเริ่มรู้สึกอยากวางแผนการเงินส่วนตัวเชิงลึก ที่ไม่เน้นคุยเรื่องทฤษฎีลอยๆ แต่เน้นกาง ตัวเลข และ Logic ของแต่ละ Solution คุยกันแบบ Fact based .. ทักมาคุยกันได้เลยครับ

คำถามที่พบบ่อย

เทคนิคสอบ CFP Module 2 วางแผนการลงทุน สำหรับคนไม่เก่งคำนวณ มีอะไรบ้าง?

5 เทคนิคหลักคือ 1) ทำข้อที่ชัวร์และง่ายก่อน อย่าให้อีโก้ลากเวลา 2) เก็บคะแนนหมวดจรรยาบรรณให้ได้มากที่สุดเพราะตรงไปตรงมากว่า Module 1 3) เข้าใจว่าสูตรอย่าง Sharpe, Treynor, SD วัดอะไร ไม่ต้องจำเป๊ะ 4) ใช้สิทธิ์ IC License ยกเว้นคอร์สเรียนถ้ามีอยู่แล้ว 5) ระมัดระวังหมวดการจัดพอร์ตและวัดผลตอบแทนที่คะแนนเฉลี่ยต่ำสุด

ถ้ามีใบอนุญาต IC อยู่แล้ว ช่วยอะไรในการสอบ CFP ได้บ้าง?

ใช้ยื่นขอ Skip การอบรมได้ ประหยัดค่าคอร์สเรียนไปได้เป็นหมื่นบาท โดยมีค่าธรรมเนียมเทียบเคียงสิทธิ์เพียงประมาณพันกว่าบาท

หมวดไหนใน Module วางแผนการลงทุนที่คนสอบส่วนใหญ่ทำคะแนนได้ต่ำสุด?

หมวดการวิเคราะห์และจัดพอร์ตลงทุน เพราะต้องเข้าใจจริงว่าทำไมต้องจัดสินทรัพย์แบบนั้นในสถานการณ์นั้นๆ และต้องคำนวณวัดผลตอบแทนด้วย ท่องจำอย่างเดียวไม่พอ
